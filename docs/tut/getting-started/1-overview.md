# Overview

**Pact** is a modern & declarative buffer networking library for Roblox, offering a high-performance, strictly typed with new solver, and modular model for events, functions, and synchronized state.

## Why Pact?

- **Typed** — Built on Luau type functions to dynamically generate autocomplete, interfaces, and casing conventions.
- **Compact** — Efficient data serialization keeps communication fast and lightweight.
- **Accessible** — No plugins, code generation steps, or external CLIs. Just require and go.
- **Secure** — Binary buffers make network traffic harder to reverse-engineer, while automatically validating all received data.
