# Installation

Pact can be installed through [Wally](https://wally.run/package/encodedlux/pact) or [Pesde](https://pesde.dev/packages/encodedlux/pact), depending on your preferred package manager.

## Wally

:::tabs
==wally.toml
```toml
pact = "encodedlux/pact@0.1.5"
```
:::

## Pesde

:::tabs
==pesde.toml
```toml
pact = { name = "encodedlux/pact", version = "^0.1.5" }
```

==pesde-cli
```bash
pesde add encodedlux/pact
```
:::
